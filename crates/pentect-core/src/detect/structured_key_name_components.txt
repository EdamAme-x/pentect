# field/configuration name rather than secret material.
#
# Format:
# - component:word
# - name:full_identifier
# - numbered_name:identifier_prefix
#
# Policy:
# - Used only for generic JSON key fields whose key name is exactly `key`.
# - `component:` entries are combined only when the value has at least two
#   normalized parts, e.g. `seedUser`, `smtpDomain`, or `apiKey`.
# - `name:` entries are full public field/header/parameter names that can stand
#   alone as metadata values.
# - `numbered_name:` entries are public UI/reference identifiers with a numeric
#   suffix, e.g. `panel1`.
# - High-risk material words such as `password` and `secret`, and concrete
#   values containing digits or token punctuation, remain detectable. Public
#   schema names such as `token` or `code` may be listed explicitly.
