# Non-secret value patterns.
#
# Format: kind:pattern
# Matching is done after identifier normalization: case-insensitive, punctuation
# collapsed to underscores, then trimmed. Keep this list small and generic.
#
# exact:
#   Conventional documentation placeholders. These values are stand-ins used in
#   examples and templates; they are not usable credentials by themselves.
#
# prefix/suffix/contains:
#   Placeholder markers that explicitly say the value was removed, redacted, or
#   supplied by the reader.
#
# numbered_prefix:
#   Synthetic sample values such as value1/value2.
#
# RFC documentation hosts/IP ranges:
#   Managed by documentation_host_patterns.txt so domain/IP CIDR rules stay in
#   one place and carry their RFC basis.
