---
title: Antigravity CLI (not implemented)
description: Current Pentect support status for Antigravity CLI.
---

::: warning Not implemented
Pentect does not currently expose an Antigravity CLI integration.
:::

`pentect antigravity` and `pentect agy` are not available in the current release and return
an unknown-command error. Starting `agy` normally does not route it through
Pentect. Do not treat that traffic as protected.

This page records planned integration status only. Availability will be
announced in the release notes after a public launcher and compatibility tests
ship.
