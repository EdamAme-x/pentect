---
title: Continue CLI (not implemented)
description: Current Pentect support status for Continue CLI.
---

::: warning Not implemented
Pentect does not currently expose a Continue CLI integration.
:::

`pentect continue` and `pentect cn` are not available in the current release and return an
unknown-command error. Starting Continue normally does not route it through
Pentect. Do not treat that traffic as protected.

This page records planned integration status only. Availability will be
announced in the release notes after a public launcher and compatibility tests
ship.
