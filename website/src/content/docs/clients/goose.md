---
title: Goose CLI (not implemented)
description: Current Pentect support status for Goose CLI.
---

::: warning Not implemented
Pentect does not currently expose a Goose CLI integration.
:::

`pentect goose` is not available in the current release and returns an unknown-command
error. Starting Goose normally does not route it through Pentect. Do not treat
that traffic as protected.

This page records planned integration status only. Availability will be
announced in the release notes after a public launcher and compatibility tests
ship.
