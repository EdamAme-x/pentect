title: Zed (not implemented)
description: Current Pentect support status for Zed.
---

::: warning Not implemented
Pentect does not currently expose a Zed integration.
:::

`pentect zed` is not available in the current release and returns an unknown-command error.
Starting Zed normally does not route it through Pentect. Do not treat that
traffic as protected.

This page records planned integration status only. Availability will be
announced in the release notes after a public launcher and compatibility tests
ship.
