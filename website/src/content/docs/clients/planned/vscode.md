::: warning Not supported yet
Pentect does not protect VS Code today. This page describes planned support only.
:::

## Planned coverage

The planned integration is a small `LanguageModelChatProvider` extension. It
will cover only traffic sent through that provider; Copilot completions and
other extensions' private HTTP traffic are separate integrations.

See the [Pentect roadmap](https://github.com/EdamAme-x/pentect/issues/114) and
[VS Code provider documentation](https://code.visualstudio.com/api/extension-guides/ai/language-model-chat-provider).
