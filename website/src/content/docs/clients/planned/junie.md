::: warning Not supported yet
Pentect does not protect Junie CLI today. This page describes planned support only.
:::

## Planned coverage

Pentect will launch Junie CLI with a temporary custom model profile and route
both its primary and faster models. The Junie IDE plugin is not covered by this
plan because it has a different integration surface.

See the [Pentect roadmap](https://github.com/EdamAme-x/pentect/issues/114) and
[Junie custom model documentation](https://junie.jetbrains.com/docs/custom-llm-models.html).
