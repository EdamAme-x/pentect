::: warning Not supported yet
Pentect does not protect Continue today. This page describes planned support only.
:::

## Planned coverage

Pentect will connect through Continue's documented `apiBase` setting. Chat, Edit,
Apply, autocomplete, embeddings, and reranking will be tested separately because
they do not all use the same request path.

See the [Pentect roadmap](https://github.com/EdamAme-x/pentect/issues/114) and
[Continue configuration reference](https://docs.continue.dev/reference).
