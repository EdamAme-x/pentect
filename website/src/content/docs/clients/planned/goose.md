::: warning Not supported yet
Pentect does not protect Goose today. This page describes planned support only.
:::

## Planned coverage

Goose CLI will start with a temporary provider configuration that points to
Pentect. Desktop support will be verified separately, and Pentect will not save
an upstream key in Goose's keychain.

See the [Pentect roadmap](https://github.com/EdamAme-x/pentect/issues/114) and
[Goose source repository](https://github.com/aaif-goose/goose).
