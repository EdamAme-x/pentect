Pentect does not protect Gemini CLI today. This page describes planned support only.
:::

## Planned coverage

Gemini CLI needs a native Gemini adapter for `generateContent`, streaming,
token counting, functions, and file data. API-key, Vertex, and Code Assist OAuth
paths will be tested separately; Cloud Code support cannot be reused as-is.

See the [Pentect roadmap](https://github.com/EdamAme-x/pentect/issues/114) and
[Gemini CLI source repository](https://github.com/google-gemini/gemini-cli).
