## Planned coverage

The planned adapter uses Roo Code's OpenAI-compatible provider. CLI and editor
traffic will be treated as separate surfaces, with tests for streamed tool
arguments and preserved tool-call IDs.

See the [Pentect roadmap](https://github.com/EdamAme-x/pentect/issues/114) and
[Roo Code provider documentation](https://roocodeinc.github.io/Roo-Code/providers/openai-compatible/).
